### Filter → Sort → Display
```
1. User selects Class "10"
   ↓
2. User selects Subject "Maths"
   ↓
3. User selects Format "PDF"
   ↓
4. Grid re-renders with animations
5. Shows only matching resources
   ↓
6. User selects Sort "Most Downloaded"
   ↓
7. Grid re-sorts and re-animates
```

### Form Submission
```
1. User fills form
2. Form validates
3. User clicks Send
   ↓
4. Button shows "Sending..."
5. Form data logs to console
6. Button shows "✓ Sent!"
7. Form resets
8. Button returns to normal (2s delay)
```

### Theme Toggle
```
1. User clicks ☀️/🌙 icon
2. HTML class toggles "light-mode"
3. All CSS variables update
4. Smooth transition (0.35s)
5. Icon swaps
6. Preference saved to localStorage
7. Persists across sessions
```
