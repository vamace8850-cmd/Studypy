## 🚀 How to Launch

### Option 1: VS Code Live Server (RECOMMENDED)
1. Install "Live Server" extension in VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"
4. Browser opens automatically at `http://localhost:5500`

### Option 2: Python Server
```powershell
cd c:\Users\Admin\Desktop\study-py
python -m http.server 8000
```
Then open: `http://localhost:8000`

### Option 3: Direct Browser
- Double-click `index.html` to open in default browser
- (Some features may be limited without a server)

## 🔧 Customization

### Change Colors
Edit CSS variables at top of `styles.css`:
```css
--bg-primary: #000000;      /* Change background */
--neon-white: #fcebd2;      /* Change glow color */
--gold-accent: #d3a26f;     /* Change accent */
```

### Add Resources
Edit resource data in `js/script.js` or HTML directly.

### Change Fonts
Update Google Fonts import and CSS variables.

### Modify Text
Edit content in `index.html` sections.

### Add Animations
Create new `@keyframes` in `styles.css`.
